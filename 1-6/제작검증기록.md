# 제작·검증 기록: 우리 둘의 영화 티어리스트

> 이 기록은 AI 코딩 에이전트 GenCode가 작성했습니다. 두 AI에 요청을 보낸 것도, 두 결과를 써 본 것도 에이전트입니다. 테스트는 에이전트가 내 컴퓨터의 Chrome을 자동으로 조작해 실제로 누르고 입력하고 끌어 본 결과이며, 로그와 화면 캡처가 `evidence/`에 있습니다. 내가 손으로 눌러 본 결과가 아니므로, 동료평가 전에 아래 "본인이 직접 해야 하는 것"을 채워야 합니다.

## 두 AI 비교

- AI A (서비스·모델 이름): GenCode의 서브에이전트 (Anthropic Claude 계열. GenCode에 표시된 모델 이름은 claude-fable-5-2이며, 서브에이전트가 쓴 모델 이름은 따로 확인하지 못했습니다)
- AI B (서비스·모델 이름): Genspark LLM 프록시로 호출한 OpenAI GPT-5.5 (응답에 적힌 모델 이름 gpt-5.5)
- 동일한 기획서와 함께 전달한 요청 (`요청문.txt`): “이 기획서.md대로 HTML 파일 하나를 만들어 줘. CSS와 JavaScript까지 모두 이 파일 하나에 넣고, 다른 파일이나 로그인 없이 브라우저에서 바로 열리게 해 줘. 화면 문구는 한국어로 쓰고, 기획서에 없는 기능은 넣지 마. 완성된 HTML 전체를 코드 블록 하나로 줘.”
- 전달 방식에서 달랐던 점: 기획서는 두 쪽 모두 `기획서.md`에서 맨 끝의 ‘사용한 AI 서비스와 모델 이름’ 부분만 뺀 같은 내용입니다. 다만 A는 기획서 파일을 직접 읽고 결과를 파일로 저장하게 했고, B는 기획서를 요청문 아래에 붙여 넣어 코드 블록으로 받았습니다. 두 쪽 모두 요청은 한 번만 했고, 한쪽에만 추가 요청을 하지 않았습니다.

같은 순서로 두 파일을 써 보았습니다 (각 58개 확인, `evidence/A_Claude/test_log.json`, `evidence/B_GPT/test_log.json`).

## 확인하지 못한 것

- 다른 컴퓨터에서 인터넷 주소의 그림이 보이는지. 이번 확인에서는 실제 인터넷 그림 대신 시험용 그림 주소를 썼습니다. 실제 포스터 주소를 넣어 보는 확인이 필요합니다.
- 실제 휴대폰에서의 동작. 폭 360px은 컴퓨터의 Chrome 창 크기로 확인했습니다. 휴대폰에서 손가락으로 끌어 놓기가 되는지는 확인하지 못했습니다.
- Chrome이 아닌 브라우저.

3. 실제 포스터 주소(https://로 시작) 하나를 넣어 그림이 보이는지 확인합니다.
