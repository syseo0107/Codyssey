# 미션 4 기록

- 사용한 AI 이름 / 주요 대화 캡처 파일명: GenCode (모델 claude-fable-5-2) / 대화 캡처는 아직 없음 (아래 "남은 일" 참고)
- 작업 방식: 웹 AI 채팅 대신 AI 코딩 에이전트(GenCode)에게 맡겨 진행했습니다. 기능을 더한 것도, 완성 기준을 확인한 것도 같은 에이전트입니다. 확인은 에이전트가 내 컴퓨터의 Chrome을 자동으로 조작해 실제로 누르고 끌어 본 결과이며, 로그와 캡처는 `evidence/원본/`, `evidence/기능추가/`에 있습니다. 손으로 눌러 본 결과가 아닙니다.
- 더한 기능과 고른 이유: 칸마다 영화 개수 보여 주기. S·A·B·C 글자 아래와 '아직 안 정한 영화' 옆에 '2편'처럼 보입니다. 영화가 늘어나면 칸마다 몇 편인지 세기 어렵고, 아직 못 정한 영화가 몇 편 남았는지 바로 알 수 있어서 골랐습니다. 또 "옮기면 한쪽은 1 줄고 다른 쪽은 1 는다"처럼 숫자로 맞는지 틀리는지 분명하게 확인할 수 있는 기능이라서 골랐습니다.
- 기획서에 덧붙인 완성 기준 (`기획서.md` 맨 끝 4줄):
  1. 등급 글자 아래와 '아직 안 정한 영화' 옆에 그 칸의 영화 수가 '0편'처럼 보인다
  2. 옮기면 원래 칸은 1 줄고 옮긴 칸은 1 늘며, 다섯 칸의 합이 전체 영화 수와 같다
  3. 영화를 추가하면 '아직 안 정한 영화'가 1 늘고, '처음으로'를 누르면 S·A·B·C는 0편, 미분류는 8편이 된다
  4. 다시 열어도 칸마다 보이는 수가 그 칸의 카드 수와 같다
- AI에게 한 요청: "영화 티어리스트에 칸마다 영화 개수 보여 주기를 추가해 줘. 첨부한 기획서의 완성 기준이 모두 맞아야 해. 원래 기능은 바꾸지 마. 수정한 HTML 전체를 줘."

| 받은 파일 | 맞지 않은 완성 기준 | 한 일 (고치기 / 원래 파일로 돌아가기 / 완성) |
|---|---|---|
| `영화_원본.html` (제공 파일, 고치지 않음) | 원래 완성 기준 7개는 모두 맞음. 새 기능 기준 4개는 아직 없음 (칸에 글자만 보이고 수는 안 보임) | 그대로 보관. 기능을 더할 출발점으로 사용 |
| `영화_기능추가.html` | 없음. 원래 기준 7개와 새 기준 4개 모두 맞음 | 완성 (완성본) |

- `영화_기능추가.html`에서 확인한 내용:

| 완성 기준 | 해 본 것 | 결과 |
|---|---|---|
| 영화가 한 칸에만 있고 옮긴 칸에 남는다 | 8개를 누르기와 끌어 놓기를 번갈아 S·A·B·C에 옮김 | 칸마다 2장씩, 카드 총수 8장. 겹치거나 사라진 카드 없음 |
| 제목을 입력하면 새 카드가 생긴다 | '어바웃 타임' 추가 뒤 누르기로 A, 끌어 놓기로 C에 옮김 | 미분류에 카드가 생기고 두 방법 모두 옮겨짐 |
| 다시 열어도 영화와 등급이 남는다 | 새로 고침, 탭을 닫고 다시 열기 | 두 번 모두 배치가 그대로 |
| 좁은 화면에서 오른쪽이 잘리지 않는다 | 폭 420·360·320px | 가로 넘침 없음, 화면 밖으로 나간 카드·버튼 0개. 등급 글자 칸 크기도 원본과 같음(폭 48px, 높이 88px) (`04_좁은화면_360.png`) |
| '처음으로'를 누르면 8개가 미분류로 | 영화를 옮기고 추가한 뒤 '처음으로' | 처음 8개가 모두 미분류, 추가한 영화는 사라짐 |
| 외부 파일·로그인·서버 없이 열린다 | 파일을 바로 열고 외부 주소 참조를 셈 | 바로 열림, 외부 주소 0개, 오류 0건 |
| 빈 제목은 추가하지 않는다 | 빈칸, 공백만 넣고 '추가' | 카드가 안 생기고 '영화 제목을 입력해 주세요.' |
| [새 기능 1] 칸마다 수가 보인다 | 파일을 열고 '처음으로' | S 0편, A 0편, B 0편, C 0편, 아직 안 정한 영화 (8편) (`01_처음.png`) |
| [새 기능 2] 옮기면 1 줄고 1 는다 | 기생충 누르기→S, 인터스텔라 끌기→S, 기생충 끌기 S→B, 인터스텔라 누르기→미분류 | 미분류 8→7→6→6→7, S 0→1→2→1→0, B 0→0→0→1→1. 매번 다섯 칸의 합이 8 |
| [새 기능 3] 추가·'처음으로' 때의 수 | 8개를 모두 나눈 뒤 '어바웃 타임' 추가, 그 뒤 '처음으로' | 추가 뒤 미분류 0편→1편. '처음으로' 뒤 S·A·B·C 0편, 미분류 8편 |
| [새 기능 4] 다시 열어도 수가 맞다 | S 2, A 2, B 2, C 3으로 나누고 새로 고침, 탭 닫고 다시 열기 | 보이는 수와 카드 수가 칸마다 같음 (`03_다시연뒤.png`) |

- 원래 기능이 망가졌는지: 같은 확인을 `영화_원본.html`과 `영화_기능추가.html`에 똑같이 해 보았고, 칸에 보이는 수를 빼면 결과가 모두 같았습니다. 망가진 기능이 없어 5)번(원래 파일로 돌아가기)은 건너뛰었습니다.
- 원본과 달라진 곳: 등급 글자를 그리는 부분에 수를 세어 붙이는 3줄, 미분류 제목에 수를 붙이는 1줄, 글자 칸의 줄 간격 1곳. 영화를 옮기고 저장하는 부분은 건드리지 않았습니다.
- 한 가지 알아 둘 점: 미분류의 수는 '아직 안 정한 영화 (8편)'처럼 제목에 괄호로 붙습니다. 등급 칸의 '8편' 표기와 모양이 조금 다릅니다.
- 남은 일 (본인이 직접 해야 하는 것):
  - 대화 캡처 이미지: 이 작업을 한 GenCode 대화 화면을 캡처해 이 폴더에 넣고, 맨 위 줄에 파일명을 적습니다.
  - `영화_기능추가.html`을 브라우저에서 직접 열어 카드를 한두 개 옮기며 수가 바뀌는 것을 눈으로 확인해 두면 동료평가에서 설명하기 쉽습니다.
- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유: 새 기능의 완성 기준을 어떻게 적었는지. "수가 보인다"만 적으면 맞는지 판단하기 어려워서 "1 줄고 1 는다", "합이 전체와 같다"처럼 적었는데, 다른 사람은 어떻게 적었는지 궁금합니다.
