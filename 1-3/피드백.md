# 민수 님께 드리는 피드백


## 잘된 점

- **조작이 매끄럽습니다.** 카드를 골라 등급 배지를 누르는 방식과 끌어다 놓는 방식이 둘 다 동작했습니다. 띄어쓰기가 있는 제목('센과 치히로의 행방불명', 추가한 '어바웃 타임')도 두 방식 모두 잘 옮겨졌습니다.
- **영화는 항상 한 칸에만 있습니다.** 옮겨도 이전 칸에 남지 않았습니다.
- **어느 칸인지 바로 보입니다.** 등급마다 배지 색이 다르고(S 빨강, A 주황, B 초록, C 파랑), 카드를 끌어 칸 위에 올리면 배경이 살짝 밝아져 놓일 곳을 미리 알 수 있었습니다.
- **진행 상황이 숫자로 보입니다.** '9편 중 2편 나눔'처럼 배치할 때마다 숫자가 바뀌어 남은 양을 세지 않아도 됐습니다.
- **HTML 한 장으로 바로 열립니다.** 외부 파일이나 로그인이 필요 없고, 외부 주소를 불러오는 곳도 없었습니다.

## 고치면 좋을 점

**1. 새로고침하면 영화와 등급이 모두 사라집니다**
- 본 것: 기생충을 S에, 인터스텔라를 A에 놓고 '오펜하이머'를 추가한 뒤 새로고침(F5)을 했더니, 목록이 처음 8편으로 돌아가고 등급 배치가 모두 사라졌습니다. localStorage에 남은 값도 없었습니다.
- 기준: 완성 기준 "같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다."
- 제안: 영화를 옮기거나 추가할 때마다 localStorage에 저장하고, 페이지를 열 때 저장된 값이 있으면 그것으로 그려 주세요. 저장된 값이 없을 때만 처음 8편을 보여 주면 됩니다.

**2. 창 폭을 줄이면 오른쪽이 잘리고, 잘린 부분을 볼 방법이 없습니다**
- 본 것: 폭 1000px에서는 다 보였지만 그보다 좁아지면 아래처럼 잘렸습니다. 가로로 휠을 굴려도 화면이 움직이지 않아(가로 스크롤 0px) 잘린 버튼은 누를 수 없었습니다 (07_창폭_768.png). 실제 휴대폰에서 어떻게 보이는지는 확인하지 못했습니다.

| 창 폭 | 보인 모습 |
|---|---|
| 1000px | 모두 보임 |
| 900px | '처음으로' 버튼과 편수 표시가 화면 밖으로 나감 |
| 768px | '추가' 버튼도 잘리고 카드 8개 중 6개만 보임 |
| 390px | 카드 3개만 보임 |
| 375px | 제목이 '민수의 영화 티어리스'에서 잘림 |

- 기준: 완성 기준 "화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다."
- 제안: .page의 고정 폭(960px)을 width: min(960px, 100%)처럼 바꾸고 body의 overflow-x: hidden을 풀어 주세요. 좁은 폭에서는 제목 입력줄과 등급 줄이 세로로 쌓이게 하면 버튼이 화면 안에 남습니다.

**3. 카드를 고른 뒤 칸의 빈 곳을 누르면 옮겨지지 않습니다**
- 본 것: 카드를 고르고 S칸의 빈 곳을 눌렀더니 옮겨지지 않았습니다. 색이 칠해진 등급 글자를 눌러야만 옮겨졌습니다.
- 기준: 칸에 '여기로 끌어 놓기'라고 적혀 있어 눌러도 될 것처럼 보였습니다. (쓰다가 불편했던 점)
- 제안: 카드를 고른 상태에서는 칸 전체를 눌러도 옮겨지게 해 주세요. 어렵다면 안내 문구를 '등급 글자를 누르거나 여기로 끌어 놓기'로 바꿔 주세요.

**4. 끌어 놓을 때 목적지 칸이 화면에 보이지 않습니다**
- 본 것: 1280×900 화면에서 '아직 안 정한 영화'의 카드(y 1058)와 S칸(y 312~468)이 한 화면에 함께 보이지 않았습니다. 카드를 잡고 화면 위 끝까지 가져가야 자동으로 스크롤되면서 겨우 S칸에 닿았습니다.
- 기준: 기획서 "카드를 끌어 놓으면 해당 칸으로 옮겨집니다." 옮겨지기는 하지만 끄는 동안 목적지가 화면에 없습니다. (쓰다가 불편했던 점)
- 제안: '아직 안 정한 영화'를 등급판 위나 오른쪽에 두거나, 끄는 동안 등급 칸이 화면 위에 붙어 있게(sticky) 해 주세요. 카드를 고른 뒤 등급 버튼만 누르는 방법이 있다는 안내를 더 앞에 두는 것도 도움이 됩니다.

**5. 제목이 비어 있어도 카드가 추가됩니다**
- 본 것: 제목을 비워 두고 '추가'를 눌렀더니 글자 없는 카드가 생겼고, 위의 숫자도 '10편 중 2편 나눔'으로 함께 늘었습니다.
- 기준: 기획서 "제목을 입력하고 '추가'를 누르면 아직 안 정한 영화에 카드가 생깁니다." 제목이 있을 때 카드가 생기는 흐름이므로 빈 카드는 의도한 동작이 아닙니다.
- 제안: 빈 값(공백만 있는 값 포함)이면 추가하지 않고 '제목을 입력해 주세요'만 알려 주세요. 입력칸에 required를 붙이면 가장 간단합니다.

**6. 같은 제목의 영화가 중복으로 추가됩니다**
- 본 것: 이미 목록에 있는 '기생충'을 한 번 더 추가했더니 같은 이름의 카드가 두 장 생겼습니다.
- 기준: 기획서에는 조건이 없습니다. 다만 같은 영화가 두 장이면 등급이 갈라져 '내 취향 정리'라는 목적이 흐려집니다. (쓰다가 불편했던 점)
- 제안: 같은 제목이 이미 있으면 추가하지 않고 '이미 목록에 있어요'라고 알려 주세요.

**7. '처음으로'가 확인 없이 직접 추가한 영화까지 지웁니다**
- 본 것: 기생충을 S에 놓고 '취향영화'를 추가한 뒤 '처음으로'를 한 번 눌렀더니, 확인 창 없이 곧바로 처음 8편으로 돌아가고 '취향영화'도 함께 사라졌습니다. 되돌릴 방법은 없었습니다.
- 기준: 기획서에는 없는 부분입니다. 처음 목록으로 돌아가는 것 자체는 기획서대로지만, 손으로 넣은 영화가 경고 없이 지워지면 다시 넣어야 합니다. (쓰다가 불편했던 점)
- 제안: '처음으로'를 누르면 확인을 한 번 받거나, 초기화 직후 '되돌리기' 버튼을 잠깐 보여 주세요. 직접 추가한 영화는 남기고 배치만 초기화하는 선택지도 좋습니다.
