## 0. 제작 지시문 (기획서와 함께 투입한 요청)

```
아래 기획서대로 HTML·CSS·JavaScript가 모두 들어 있는 HTML 파일 하나를 만들어 줘.
외부 파일이나 서버 없이 브라우저에서 바로 열리게 하고, 화면 문구는 한국어로 써 줘.
완성된 .html 파일로 제공해 줘.
```

## 1. 누가 쓰나 (Target User)

- 본인과 애인 (2인 전용)

## 2. 무엇을 하려고 하나 (Purpose & Scope)

- 목적: 두 사람만의 영화 관람 기록 및 취향 랭킹 구축
- 대상: 최근 7년 동안 한국에서 개봉한 영화 중 직접 선택한 작품들

## 3. 화면과 동작 (UI & Interactions)

- 티어표(랭킹) 구성 및 분류 방식
  - 기본 감성 문구 제공 (예: 남에게 추천할만한 인생작 / 또 보고 싶은 / 무난함 / 아쉬움)
  - 랭킹 설정 기능: 티어 명칭 및 단계를 직접 수정·추가·삭제할 수 있는 관리 기능
- 개별 영화 카드 (상세 정보 & 입력)
  - 영화 포스터, 제목, 개봉일
  - 두 사람 각자의 평점 및 한 줄 평
  - 함께 본 날짜
  - 함께 찍은 대표 사진 (1~2장)
  - 같이 먹은 음식 및 당시 추억 기록
- 데이터 저장 및 배포
  - 1차: 내 기기 브라우저 저장 (로컬 저장)
  - 2차 (추후): Netlify / Vercel 배포 또는 앱 전환 고려

## 4. 필요한 자료 (Data & Assets)

- 영화 기본 정보 (자동 + 수동)
  - 영화 제목 검색 시 포스터와 개봉일을 불러오는 영화 데이터 API
  - 포스터 이미지 파일 업로드 기능 및 텍스트 직접 수정 기능
- 개인 기록 데이터
  - 대표 사진 파일 (영화당 1~2장)
  - 두 사람의 평점, 한 줄 평, 관람일, 함께 먹은 음식, 추억 기록 텍스트

## 5. 완성 기준 (Definition of Done - MVP)

- DoD-1. 내 컴퓨터 브라우저에서 영화 5개를 직접 검색하고 등록할 수 있다.
- DoD-2. 등록 시 자동으로 불러온 영화 정보(제목/개봉일/포스터)를 원하는 텍스트와 이미지 파일로 수정할 수 있다.
- DoD-3. 등록한 영화 카드에 두 사람의 평점, 한 줄 평, 관람일, 대표 사진(1~2장), 함께 먹은 음식, 추억 기록을 입력하여 저장할 수 있다.
- DoD-4. 영화 카드를 다른 티어 칸으로 이동시키거나 티어 설정을 변경한 뒤, 브라우저를 새로고침하거나 껐다 켜도 변경한 위치와 입력 데이터가 그대로 유지된다.
