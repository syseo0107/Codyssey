# 기획서 도출 질의응답 로그 (AI 질문 유도 기록)

- 성격: 기획서(`기획서.md`)가 나오기 전, 다른 AI가 먼저 질문을 던지고 사용자가 답하는 방식으로 요구사항을 구체화한 대화 기록
- 출처: 사용자가 2026-11-02 17:21 프로젝트 "Bea" 채팅에 붙여 넣은 원문 (AI 주도 질문 → 사용자 답변)
- 용도: 평가 항목 "AI가 먼저 질문했다는 대화 시작·질문유도 로그" 증빙

---

## 1차 질의응답 (프로젝트 목적 및 기본 개념 설정)

### Q1. 서비스 목적 및 사용자
- 질문(AI): 누가 쓰고, 서비스 목적은 무엇인가요?
- 답변(사용자): 본인과 애인 단 둘이서만 사용하는 기록용 웹페이지. 최근 7년 동안 한국에서 개봉한 영화 중 직접 선택하여 둘만의 랭킹(티어)을 만들고, 각자의 평점 및 함께했던 사진과 추억 기록을 남기는 아카이브 용도.

## 2차 질의응답 (화면 구성 및 동작 상세)

### Q2-1. 티어표(랭킹) 구성과 분류 방식
- 질문(AI): 티어 기준 및 구성 방식은 어떻게 할 것인가요?
- 답변(사용자): "남에게 추천할만한 인생작 / 또 보고 싶은 / 무난함 / 아쉬움" 같은 감성적인 문구로 구성하되, 사용자가 직접 티어를 추가/수정/삭제할 수 있는 '랭킹 설정 기능'을 포함함.

### Q2-2. 개별 영화 카드 항목
- 질문(AI): 영화 카드에 어떤 상세 정보가 들어가야 하나요?
- 답변(사용자):
  - 영화 포스터, 제목, 개봉일
  - 나와 애인 각자의 평점 및 한 줄 평
  - 함께 본 날짜
  - 함께 찍은 대표 사진 (1~2장)
  - 같이 먹은 음식 및 당시 추억 기록

### Q2-3. 데이터 저장 방식
- 질문(AI): 데이터 저장 및 배포 환경은 어떻게 구상하고 있나요?
- 답변(사용자):
  - 1차: 본인 기기 브라우저 로컬 저장 방식
  - 2차: 추후 Netlify 또는 Vercel을 통한 배포, 혹은 앱 전환 염두

## 3차 질의응답 (필요 자료 및 완성 기준)

### Q3-1. 영화 기본 정보 입력 방식
- 질문(AI): 포스터와 제목 등 기본 정보는 어떻게 가져오나요?
- 답변(사용자): 영화 제목 검색 시 자동으로 포스터와 개봉일을 불러오는 API 연동 방식 활용. 필요한 경우 포스터 이미지 업로드 및 텍스트 직접 수정이 가능해야 함.

### Q3-2. 사진 저장 방식
- 질문(AI): 함께 찍은 사진은 몇 장 정도 첨부하나요?
- 답변(사용자): 대표 사진 1~2장 정도 첨부.

### Q3-3. 1차 완성 기준 (MVP 기준)
- 질문(AI): 웹페이지가 완성되었음을 직접 검증할 수 있는 행동 문장은 무엇인가요?
- 답변(사용자):
  - 내 컴퓨터 브라우저에서 영화 5개를 직접 검색하고 등록할 수 있다.
  - 등록 시 자동으로 불러온 영화 정보(제목/개봉일/포스터)를 원하는 텍스트와 이미지 파일로 직접 수정할 수 있다.
  - 등록한 영화 카드에 두 사람의 평점, 한 줄 평, 관람일, 대표 사진(1~2장), 함께 먹은 음식, 추억 기록을 입력하여 저장할 수 있다.
  - 영화 카드를 다른 티어 칸으로 이동시키거나 티어 설정을 변경한 뒤, 브라우저를 새로고침하거나 껐다 켜도 변경된 위치와 입력 데이터가 그대로 유지된다.
